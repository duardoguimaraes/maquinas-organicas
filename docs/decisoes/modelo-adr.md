# Modelo de registro de decisão arquitetural (ADR)

Use este modelo quando houver uma decisão técnica relevante que mereça ser compreendida no futuro. Não é necessário criar um ADR para cada ajuste pequeno.

## ADR-XXX — Título da decisão

- **Status:** Proposta / Aceita / Substituída
- **Data:** AAAA-MM-DD

### Contexto

Qual problema, necessidade ou restrição motivou a decisão?

### Alternativas consideradas

Quais opções foram consideradas? Registre apenas alternativas realmente avaliadas.

### Decisão

O que foi escolhido e por quê?

### Consequências

Quais benefícios, custos, limitações ou dependências decorrem da decisão?

### Validação

Como a decisão será verificada? Se ainda não foi testada, registrar isso explicitamente.
