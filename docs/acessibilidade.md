# Acessibilidade — Máquinas Orgânicas

## Objetivo

Registrar as referências e verificações de acessibilidade do portfólio. Este documento descreve critérios de avaliação; não declara conformidade integral com as WCAG.

## Referência principal

As [Web Content Accessibility Guidelines (WCAG)](https://www.w3.org/WAI/standards-guidelines/wcag/), publicadas pelo W3C, organizam recomendações em quatro princípios:

- **Perceptível:** informações devem poder ser percebidas pelos usuários. Para imagens informativas, avaliar alternativas textuais adequadas.
- **Operável:** navegação e controles devem poder ser utilizados por diferentes formas de interação, incluindo teclado.
- **Compreensível:** textos, rótulos e organização devem favorecer o entendimento.
- **Robusto:** o conteúdo deve buscar compatibilidade com navegadores e tecnologias assistivas.

## Pontos a verificar

- [ ] Conferir se cada imagem possui texto alternativo (`alt`) apropriado à sua função.
- [ ] Verificar se a estrutura HTML utiliza elementos semânticos adequados.
- [ ] Avaliar contraste entre texto, fundo e elementos de destaque.
- [ ] Verificar a visibilidade do foco durante a navegação por teclado.
- [ ] Percorrer a página usando apenas o teclado.
- [ ] Conferir a compreensão dos títulos, seções e legendas.
- [ ] Testar a apresentação em diferentes larguras de tela.
